# Empire Refactored: Specialists & Governors v1.0

## 1.0.3 - Battle Fix
- Date: 2026-07-05
- Type: Patch
- Authors: Matathias

Fixes an issue where, after a battle, specialists from the wrong settlement could die.

### Changes
- Bugfix: when Settlement A is under attack and a squad from Settlement B is sent to defend, on battle resolution, a specialist from Settlement B could die, instead of A

## 1.0.2 - Backend XML Update
- Date: 2026-06-28
- Type: Patch
- Authors: Matathias

Just an update of the xml patches; user-facing behavior shouldn't change.

### Changes
- Use PatchOperationConditional to patch orbital settlements instead of PatchOperationAdd with success=Always, which is outdated semantics

## 1.0.1 - Update Specialist Death Handling
- Date: 2026-06-27
- Type: Minor
- Authors: Matathias

A couple changes to how specialist death is handled.

### Changes
- The player now always receives a letter if a specialist dies, whether it was in battle or not.
- The RNG roll for post-battle specialist death only runs for auto-defense battles
